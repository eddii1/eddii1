# Eduard Tudoran

AI and backend engineer, based in Milan.

I build LLM systems that can be measured. Most teams shipping AI features change a
prompt or swap a model and have no way to tell whether it improved or degraded, so I
tend to build the evaluation layer alongside the pipeline rather than after it.

Previously founding engineer at **MidFlow**, an early-stage workflow-automation startup,
where I built the document-understanding pipeline (multimodal extraction with
schema-constrained decoding), the LLM evaluation and regression harness, and the
cross-platform execution engine.

**Now:** building an agentic triage pipeline on LangGraph at **FOREO**.

### Selected work

- **[Solar Rooftop Segmentation & Ranking](https://github.com/eddii1/solar-ranking-ml)** ·
  U-Net with a ResNet34 encoder for rooftop segmentation on the INRIA dataset (0.745 IoU),
  ranking buildings by estimated annual solar yield. An open-source alternative to Project
  Sunroof that needs no LiDAR or 3D data.
- **[MCP Model Serving Platform](https://github.com/eddii1/mcp-payment-delay)** ·
  An ML model served behind a FastAPI REST API and exposed as tool-callable functions
  through an MCP server, so LLMs can discover and invoke it autonomously.
- **Entrance Exam Hybrid RAG** · Domain-specific retrieval fusing pgvector semantic search
  with BM25, with structure-aware chunking and LLM-generated captions that make diagrams
  retrievable from text queries.
